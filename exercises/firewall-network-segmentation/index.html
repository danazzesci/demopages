Firewall and Network Segmentation

Segmentation determines where systems are connected. Firewall rules determine what traffic is allowed across those connections.

A connection gives data a path to follow. A firewall checks rules to decide whether that data may pass. Try changing one thing at a time and watch what happens.

Policy console · You control the rules

A policy is a set of rules. Use this console to decide which requests may pass, then test your choices. Source means the sender; destination means the receiver. A port is a numbered endpoint for a service. Here, TCP 443 is used for secure web traffic (HTTPS), and TCP 5432 for database requests. TCP is a protocol—a set of communication rules—used to deliver data reliably.

About this model: Lines show paths between network areas; data does not have to pass through each server. The DMZ (demilitarized zone) is a separate area for public-facing systems, such as a web server. The application runs the service’s internal logic, and the database stores its data. These examples assume replies to allowed requests can return. Letting the Internet or web server reach the database directly demonstrates a risky rule change. Reset clears the animation; Restore secure defaults restores the starting rules and connections.
