Firewall and Network Segmentation

Segmentation determines where systems are connected. Firewall rules determine what traffic is allowed across those connections.

Read the connections: The horizontal line is a simplified network path, not a requirement that each server forwards packets. Dashed boxes identify separate network zones; labeled controls enforce traffic policy at their boundaries.

Read the rules: These examples permit public web requests, web-server updates, and application database queries. Removing a network path and blocking traffic with a firewall are different security controls.
