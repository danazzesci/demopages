Field guide

SIEM
A system that brings together security records for investigation.
Source / destination IP
The endpoints of an event. All addresses here are documentation addresses. Flow byte directions are relative to the gateway, even on incoming authentication exchanges.
Outcome
The overall result of one event. Password success alone does not mean a session was created.
MFA
Multifactor authentication. “Not reached” means password verification did not proceed to MFA.
Session ID
A correlation identifier for an established session; null means none is recorded.
Bytes
Network payload counters from edge-flow records only. Out = sent by gateway; in = received by gateway. Do not add application records to traffic totals.
Observation → inference → conclusion → action
Observation: what a record says. Inference: a possible explanation. Conclusion: an assessment with stated confidence and limits. Action: who should do what next.
Monitoring coverage
Gateway application, identity provider, host health and gateway-edge flow records, August 10–15, 2026 PT. No payload capture, endpoint forensics, downstream bank settlement logs, or other hosts. Small transfers and unmonitored channels are not ruled out.
