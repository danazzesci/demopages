Set up an authenticator for danschaupner.com

Supported apps: Apple Passwords on iPhone, Google Authenticator on Android, Microsoft Authenticator, and Duo Mobile. Using a different app or unsure whether yours works? Email info@danschaupner.com with the app name and your device.

  1. Open the guide for your app below. Add a new entry using the QR code or, if the app supports it, the manual setup key. Keep both private.
  2. Check the label your app gave the new entry. It may show danschaupner.com, your signup email, or a generic label. If you can name or rename it, use danschaupner.com and add your signup email if you have multiple accounts. If you keep the app’s label, make a note of which entry belongs to this site.
  3. Enter the current six-digit code from that entry below and select Verify and continue. Use the same entry the next time you sign in.
Enter the setup key manually
  1. Copy the Manual setup key above. Keep it private.
  2. In your authenticator app, add an account and choose its manual setup option. In Apple Passwords, open your site entry and select Edit → Set Up Code → Use Setup Key. In Google Authenticator, choose + → Enter a setup key.
  3. If asked for an account name, enter danschaupner.com. You can add your signup email to distinguish multiple accounts. Paste the setup key and choose Time based (TOTP) if prompted. Save the entry.
  4. Find the new entry and type its current six-digit code into Six-digit code below. Select Verify and continue.

If your app only offers a QR scanner, use one of the manual setup options above, or start setup on a computer and scan the QR code with your phone.

Apple Passwords (iPhone)
  1. Open Camera and scan the QR code displayed on another screen, then select your danschaupner.com entry in Passwords.
  2. If the QR code is on your iPhone, touch and hold it and choose Add Verification in Passwords if offered. You can also open the site entry in Passwords, tap Edit → Set Up Code → Use Setup Key, and paste the manual setup key.
  3. Open Codes or the site entry in Passwords to find the six-digit code.
Google Authenticator (Android)
  1. Open Google Authenticator and tap +.
  2. Choose Scan a QR code and scan the code above. For manual setup, choose Enter a setup key, name the entry danschaupner.com, paste the key, and select Time based if prompted.
  3. Find the new entry by site name or signup email and use its current code.
Microsoft Authenticator
  1. Open Microsoft Authenticator and tap +.
  2. Choose Other account and scan the QR code above.
  3. Find the newly added entry by site name or signup email and use its current code.
Duo Mobile
  1. Open Duo Mobile, tap Add, and choose the QR scanner.
  2. Scan the QR code above. Duo may show Third-Party with your signup email underneath. If you rename the entry, use DanSchaupner.com Members and keep the email if it helps distinguish accounts.
  3. Open that entry and use its current six-digit passcode.
I already use MFA for GitHub

If you use an authenticator app for GitHub, add this QR code as a separate entry in that same app. For this site, use the code beside danschaupner.com or your signup email. If you use GitHub Mobile approval, choose one of the authenticator apps above for this site.

Lost access to your authenticator? Contact Dan at info@danschaupner.com for help recovering your member access.
